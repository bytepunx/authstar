- Kept to MS-0009's split with S-0008 (settled reply): S-0007 adds beside S-0008's changes in the five shared paths and leaves them as they are.
- Criterion 4 is blocked by two harness gaps: web's in-cluster JWKS (I-0007, D-0019) and the placeholder `sk_test_` key in `integration/scripts/lib-secrets.sh`. Asked on TH-0034, recommending A: write the step with skips and leave the criterion unticked.
- Resolved TH-0014, which the operator had answered by setting the cost of delay inputs, and TH-0023, the planner's plan thread, which TH-0034 carries on.
- T-0051: the relaxed read requires an `ok` token naming the route's tenant and `status=active`. A missing filter answers 403 for non-managers. Recorded as ADR-0112 (accepted, refines ADR-0041 and ADR-0065). Plain accounts also see each mapping's `grantedRoles` and limits; the ADR defers a display-only route.
- T-0055: the upgrade router lives in its own `upgrade.rs`, not `router.rs`, and forwards web's response unchanged without following redirects. I capped the forwarded body at 64 KiB, since the form carries only a plan id.
- T-0057: `CheckoutSessionError` tells keep's two 409s apart by keep's `error` text. Organization scope is typed but not used by the page.
- T-0061: the return origin is `X-Forwarded-Host` (portcullis overwrites any value the client sent) with `X-Forwarded-Proto`, falling back to the request's origin. The 303 is allowed only to `https://checkout.stripe.com`. No `customerEmail` is sent, because the session's email is the provider's `sub`. I widened T-0061's touches to `web/playwright.config.ts` and `web/spec/fixtures/fake-tower-server.ts`, so that the list and the choice run in web's Playwright e2e. The pages' raw Tailwind classes match the existing `(hosted)` pages; web has no tokens yet.
- Testing departure from `delegation.md`: `flai test` ran the whole suite and failed in steward's e2e, because S-0013 ran steward's Playwright at the same time on the same fixed ports (I-0010, bumped). So the task sub-agents ran cargo, vitest, `npm run check`, and Playwright by hand in their own projects. web's e2e is in no tier anyway (D-0030). A later `flai test` at T-0071 (after 42da1e0's parent) passed the whole tier.
